ШИНОБИ: АРЕНА 5.35 — ANDROID STUDIO PROJECT

Это НЕ готовый APK. Это полный проект Android Studio, содержащий игру 5.35 и новую иконку.

Сборка APK:
1. Откройте эту папку в Android Studio (File > Open).
2. Дождитесь загрузки Gradle и установки Android SDK Platform 35, если понадобится.
3. Выберите Build > Build Bundle(s) / APK(s) > Build APK(s).
4. APK будет в app/build/outputs/apk/debug/app-debug.apk.

Сборка без Play Market, подпись debug от Android Studio.
Первый запуск проверяйте на телефоне с Android 8+, WebView должен быть обновлён.
Пакет приложения: com.shonobi.arena.
Работает через встроенный локальный HTTP-сервер 127.0.0.1:порт; игра и ассеты в APK.
Интернет нужен только для сетевого мультиплеера.
