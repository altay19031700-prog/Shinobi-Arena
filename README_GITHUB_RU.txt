ШИНОБИ: АРЕНА 5.36 — ЗАГРУЗКА И СБОРКА APK ЧЕРЕЗ GITHUB

1. Распакуй весь ZIP в одну папку на Windows.
2. Установи Git for Windows (https://git-scm.com/downloads/win), если ещё нет.
3. Дважды щёлкни UPLOAD_TO_GITHUB.cmd. При запросе GitHub пройди вход через браузер.
4. После успешного push открой https://github.com/altay19031700-prog/Shinobi-Arena/actions.
5. Дождись завершения Build Shinobi Android APK. В разделе Artifacts скачай Shinobi-Arena-5.36-debug-APK.
6. Распакуй скачанный артефакт — внутри app-debug.apk.

ВНИМАНИЕ: GitHub-репозиторий сейчас PUBLIC! Другие люди смогут видеть исходный код и игровые ресурсы. Если это нежелательно, сначала поставь PRIVATE в настройках репозитория.
