# Шиноби: Арена — Android

Репозиторий для сборки Android APK версии 5.36 с улучшенными звуками и иконкой ниндзя.

## Загрузка полного игрового проекта

1. Скачайте архив `Shinobi_Arena_536_AUDIO_Android_Studio.zip` из чата и **распакуйте** его.
2. На странице репозитория откройте **Add file → Upload files** и загрузите **содержимое** распакованной папки, сохранив структуру (особенно `app/src/main/assets/assets/`, `app/src/main/java/`, `app/src/main/res/`, `app/build.gradle`, `build.gradle`, `settings.gradle`).
3. Нажмите **Commit changes**.
4. Откройте вкладку **Actions → Build Shinobi Android APK → Run workflow** (или дождитесь автоматического запуска после загрузки).
5. В завершённом запуске скачайте артефакт `Shinobi-Arena-5.36-debug-APK`. Внутри будет `app-debug.apk`.

**Важно:** пока игровые файлы не загружены, APK не может быть собран. APK необходимо проверить на Android; это тестовая сборка.
