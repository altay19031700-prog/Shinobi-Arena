# Шиноби: Арена — APK для Android

Здесь настроена автоматическая сборка **«Шиноби: Арена 5.36»** с 19 новыми звуковыми эффектами и иконкой ниндзя.

## Как получить APK

1. Скачайте архив **SHINOBI_536_GITHUB_UPLOAD_READY.zip** из чата и распакуйте на Windows.
2. Установите [Git for Windows](https://git-scm.com/downloads/win), если Git ещё не установлен.
3. Запустите **UPLOAD_TO_GITHUB.cmd** из распакованной папки. При запросе авторизуйтесь в GitHub в браузере.
4. После завершения загрузки откройте [Actions](https://github.com/altay19031700-prog/Shinobi-Arena/actions). Запуск **Build Shinobi Android APK** должен начаться автоматически.
5. Если автоматический запуск не появился, выберите **Build Shinobi Android APK → Run workflow**.
6. После успешной сборки скачайте артефакт **Shinobi-Arena-5.36-debug-APK**, распакуйте его и установите `app-debug.apk` на Android.

**Важно:** пока Android-проект не загружен, Action выдаёт ошибку проверки файлов. Первый запуск до загрузки исходников не является готовым APK.

**Внимание:** репозиторий сейчас **публичный**. Если не хотите открывать исходный код игры всем, измените видимость на Private в GitHub Settings → General → Danger Zone до загрузки файлов.

APK пока не протестирован на физическом Android.
